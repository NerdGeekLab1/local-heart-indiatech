# RoamYoo product review PowerPoint

## Deliverable
Create a standalone, editable `.pptx` presentation in Files. It will not add or modify any app page.

## Content
- Open with RoamYoo’s purpose, MVP status, product-review perspective, and founder Sunny Ahlawat.
- Use only verifiable public facts for the founder; clearly label anything that could not be independently verified.
- Explain the platform by audience: foreign traveller, host, trip leader, Beta Wanderer, creator, hotel partner, and administrator.
- Show the major end-to-end journeys: discovery, registration, onboarding, booking, rewards, content creation, partner approval, and administration.
- Highlight platform-wide and differentiated capabilities, trust/safety, monetisation, current strengths, and honest MVP gaps.
- Include a complete, grouped route directory covering all registered routes, what each route does, and who uses it.
- End with a product-review verdict and practical next priorities rather than invented traction claims.

## Visual direction
- Premium editorial travel aesthetic using the existing Golden Hour identity: saffron, ink, warm white, and restrained green.
- Use embedded project travel photography, maps/process diagrams, role-based capability cards, route maps, and journey timelines.
- Keep body text presentation-readable; use appendix slides for dense route coverage.
- Add subtle PowerPoint-safe transitions/animation where supported, while ensuring the static deck remains complete.

## Technical details
- Build in 16:9 with editable text and shapes using PptxGenJS.
- Embed all image assets directly so the deck works offline.
- Add source notes for externally researched founder facts.
- Validate the `.pptx`, extract its text, render all slides, inspect them visually, fix defects, and re-verify before delivery.
